# README 更新计划

## 一、项目调研结论

**项目名称**：harmless  
**项目类型**：中国象棋（Chinese Chess / 象棋）引擎与图形界面  
**作者**：timebug（2011-2015）  
**开源协议**：GNU General Public License v3

### 核心架构
项目采用 **C 语言引擎核心 + Python (pygame) 图形界面** 的双层架构：

```
harmless/
├── src/              # C 语言象棋引擎（AI 核心）
│   ├── harmless.c    # 主入口，UCCI 协议初始化
│   ├── ucci.c        # UCCI 通信协议实现
│   ├── search.c      # 搜索算法（Alpha-Beta，深度 5 层）
│   ├── evaluate.c    # 局面评估函数
│   ├── genmoves.c    # 走法生成器
│   ├── movesort.c    # 走法排序
│   ├── position.c    # 棋局表示与操作
│   ├── hash.c        # 置换表（Zobrist Hash）
│   ├── openbook.c    # 开局库（BOOK.DAT）
│   └── pipe.c        # 管道通信
│
└── pycchess/         # Python 图形界面
    ├── cchess.py     # 主程序入口
    ├── chessboard.py # 棋盘逻辑与绘制
    ├── chessman.py   # 棋子逻辑
    ├── chessnet.py   # 网络对战（TCP 端口 62222）
    ├── common.py     # 常量与工具函数
    ├── image/        # 棋盘与棋子图片资源
    └── sounds/       # 音效资源（移动/吃子/将军）
```

### 已确认的功能特色
1. **AI 对战模式**：通过 UCCI 协议与 C 引擎通信，默认搜索深度 5 层
2. **网络对战模式**：支持 TCP Socket 双人远程对战（端口 62222）
3. **开局库支持**：内置 BOOK.DAT 开局库
4. **Alpha-Beta 搜索**：带置换表优化的极小化极大搜索
5. **FEN 局面格式**：支持标准 Forsyth-Edwards Notation
6. **音效反馈**：走子、吃子、将军三种音效
7. **跨平台**：支持 Linux / macOS / Windows
8. **图形界面**：pygame 实现的可视化棋盘，选中/走子/胜负标记
